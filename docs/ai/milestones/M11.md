## 工程与内容边界

- `docs/site` 是独立 pnpm workspace，运行时代码仍在 `packages/*`。
- 文档站不进入根 TypeScript project references，根 build 只构建 runtime packages，
  运行时镜像不复制文档站。配置真源为根 `package.json`、`pnpm-workspace.yaml`、
  `tsconfig.json` 和 `deploy/Dockerfile`。
- 站点采用 Astro Starlight。版本和 Node 下限读 `docs/site/package.json`，不在计划中
  复制容易失效的版本表；当前 CI 的 Node 选择见 `.github/workflows/ci.yml`。
- 用户内容来自示例、专题说明与实现核验，禁止直接发布 `docs/ai/*`、路线图或内部
  维护元数据。贡献者文档可以链接 `AGENTS.md` 和 `.agents/skills/`。
- 页面位于 `src/content/docs/en/` 和 `zh-cn/`；站点路由统一加 `/en/`、`/zh-cn/`
  前缀。根页负责语言选择，无脚本时有回退入口。Starlight UI 翻译使用 BCP-47 文件名。
- sidebar、域名、页面元数据和主题配置以 `astro.config.mjs` 为准；静态资源在 `public/`。

## 验证入口

`pnpm docs:build` 和 `pnpm docs:check` 先执行依赖补丁、校验器单测及以下检查，
再分别运行 Astro build/check；完整命令真源在 `docs/site/package.json`。

| 检查 | 实现 |
| --- | --- |
| 公开/内部内容边界 | `docs/site/scripts/validate-public-content.mjs` |
| Zod 字段与双语配置参考双向一致性 | `docs/site/scripts/validate-config-reference.mjs` |
| CLI 参数、dispatch 与 help 文档 | `docs/site/scripts/validate-cli-reference.mjs` |
| 站内链接、锚点、静态资源与 sidebar | `docs/site/scripts/validate-internal-links.mjs` |
| 标题、描述、robots 和分享图片 | `docs/site/scripts/validate-seo.mjs` |
| 双语页面集合、代码块机器字段与语言标记 | `docs/site/scripts/validate-bilingual-consistency.mjs` |

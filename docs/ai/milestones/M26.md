## 修复与回归

| 级别 | 问题与影响 | 修复和证据 |
| --- | --- | --- |
| 高 | worker 先租借快照，副本随后采用同一 head 时重建 generation 并覆盖缓存，旧 lease 从统计中消失；drain 可提前关闭资源 | 复用已存在的 generation，独立记录所有存活 entry，prepare 期间持有 lease；`runtime-config.test.ts` 验证对象身份、仅准备一次、排空等待及只释放一次 |
| 中 | lease 正等待历史快照 I/O 时没有 active lease，drain 可先关闭 manager | 把异步 lease 加载计入 pendingTasks；屏障测试证明加载完成和 lease 释放前 drain 均不结束 |
| 中 | 同一实体多次暂存只按 record ID 合并完整替换操作，后一次编辑丢失前一次字段 | 保留原始基线与累计 session，重新编码操作；真实浏览器断言两个字段一并进入唯一新 revision，并验证全局字段撤回与丢弃 |
| 中 | 旧输出规则的 `match.trigger` 未纳入引用收集，删除后留下无效规则 | 纳入共享引用检查；`config-publish.test.ts` 验证独立删除拒绝且 head 不变，同批移除规则可通过 |
| 中 | 混合路径模板的绝对前缀、尾部分隔符和非法字符直到事件渲染才被拒绝 | AST 字面量在编译时校验；七种路径边界及发布 prepare 阴性用例，确定非法的定义不落库 |
| 中 | 恢复 `globals: {}` 时把空路径当作所有文件锁的父路径，错误拒绝正常恢复 | 空 globals 不产生文件锁比较；测试从非空全局配置恢复为空，并提交新 revision |
| 中 | 直接调用 `previewConfigChangeset` 未传 formatVersion 时把当前 v2 revision 按 v1 校验 | 缺省沿用当前 revision，空库仍默认 v1，显式版本仍受验证；测试 v2 成功、显式不兼容失败及零 revision/audit 写入 |

原有缺陷由定向测试复现后修复：core/runtime 四项失败、混合模板五项失败，
浏览器原实现把先暂存的 timeout 从 24000 恢复为 1000。修复后定向四个文件
155 项测试及两个浏览器流程通过。后续全量门禁见下节。

新增回归共 15 项（13 项 Vitest、2 项浏览器）。全量浏览器测试还捕获本次暂存修复
清空引用缓存造成的回归：同页第二个 channel 缺少 trigger 选项。最终实现仅重建
暂存选项叠加层，保留服务器选项，继续由原 P7 运行隔离场景验证。

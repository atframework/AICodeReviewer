# M35 品牌图标与静态资源

以 `docs/site/public/favicon.svg` 为可编辑的品牌主文件，采用深海军蓝底、
冰蓝代码括号和薄荷绿审查确认符号。手动运行
`pnpm --filter @aicr/docs-site generate:brand-assets` 导出 32px 浏览器图标、
180px 触屏图标、512px 应用图标、1200x630 分享图，以及文档导航和管理面板
使用的 SVG 副本。管理面板通过固定的 `/dashboard/favicon.svg` 路由提供图标；
文档站的双语首页、导航栏、浏览器标签和社交预览采用同一视觉体系。

`.gitattributes` 将图像、字体、媒体、归档和可执行二进制纳入 Git LFS，
保留原有的模型目录 LFS 规则。文档构建检查 PNG 尺寸与 SVG 副本一致性；
管理面板路由测试覆盖根路径和带前缀的部署路径。文档站工作流已在 checkout
阶段启用 LFS，运行时镜像从已构建的 `packages/server/dist/dashboard` 复制图标。

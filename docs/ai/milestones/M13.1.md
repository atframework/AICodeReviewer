# M13.1：Agent Web Search 治理与搜索引擎配置

## 状态

已完成（2026-08-27）。

## 目标

把 agent CLI 内置搜索工具纳入 AICR 的显式治理面。默认评审必须保持封闭；运维开启后，
仅向对应 agent 注入它实际支持的 provider 配置与凭据引用，且密钥不得写入 runtime bundle。

## 已交付设计

- `agent.web_search` 提供 `enabled`、`providers`、`exclude`、`timeout_seconds`、
  `credentials` 与 `searxng`，默认 `enabled: false`。配置沿 bootstrap → orchestrator →
  runtime bundle → adapter 传递，manifest 记录 `webSearch.{enabled,mode}`。
- oh-my-pi 写入 `config.yml` 的 `web_search.enabled`、`providers.webSearch*` 与
  `searxng.*`，支持 16 个经 CLI/源码核验的凭据 env 名，包括 SearXNG token 与 Basic Auth。
- kilo 只接受 Exa：写入 `permission.websearch`，启用时注入 `KILO_ENABLE_EXA=1`，并把
  `credentials.exa` 映射到 `EXA_API_KEY`。
- opencode 只接受 Exa/Parallel：按 `providers` 顺序选择第一个支持项，通过
  `OPENCODE_ENABLE_*` 与 `OPENCODE_WEBSEARCH_PROVIDER` 固定后端，且只注入所选后端凭据。
- claude-code 与 copilot-cli 只提供开关：禁用时分别追加
  `--disallowedTools WebSearch` 与 `--excluded-tools=web_search,web_fetch`。zoo/pi 不适用。
- 不支持的 provider id/字段以启动告警跳过，便于一份全局配置服务混合 agent workspace。
  禁用搜索时不注入任何搜索凭据；所有启用凭据只以 `${VAR}` env 名引用进入子进程环境。
- kilo 的 `XDG_CONFIG_HOME`/`XDG_DATA_HOME` 指向每次运行的 bundle 内目录，避免宿主全局配置
  或跨版本 SQLite 状态污染评审。

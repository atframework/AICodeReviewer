## 浏览器门禁运维合同(供后续任务复用)

- fixture 共享持久配置命名空间:任何 spec 发布调度类配置(如
  `review.pull_request.schedule.rules` 周窗口,M16 持久延期)会把后续 webhook
  review 延迟到下一窗口。受影响的 spec 须在触发前清理,且清理必须在 config
  标签页加载前完成——带外推进 head 会使 UI 已读基线过期,首个 UI 发布 409。
- agent stub 调用是跨进程条件(webhook→调度→VCS→bundle→spawn→写日志),
  Playwright `expect.poll` 默认 10s 在冷启动全量运行下过紧,该类 poll 用 60s
  显式预算。DOM 内断言不在此列。
- stub 服务(git-main :9399 / git-preview :9398)是 HTTP JSON 替身,不说 git
  协议;review diff 来自 start-fixture 预播种的本地 clone(确定性 SHA)。

| GitLab project_id 未纳入目的地授权 | 收集 project_id（含旧 file alias）；字符串路径和数值项目 ID 两个回归证明原授权可用、改项目拒绝、新授权恢复 |

| 浏览器仅改 route/agent，缺 UI 创建实体到实际执行及 provider/model 隔离 | 补 UI provider/group/workspace/route 创建和运行中修改，断言 CLI bundle URL/model、完成 revision、快照、输出数量；测试工作目录收敛到 build/tmp，agent 屏障超时明确失败 |

## 验证环境与边界

初始工作区另有三处未提交的自动批次发布恢复改动：memory/sqlite auto-commit store
以及 server bootstrap test。它们缺少关联类型/模块，导致原工作区 typecheck 和
server 测试加载失败。本轮保留这些既有修改；SQLite 文件仅额外调整上述连接清理。
验证副本包含当前审查修改，以 HEAD 替代这三段未完成改动，并重新应用 SQLite
初始化修复。副本为 `build/tmp/p8-validation`，日志位于其 `build/logs/`。

Windows 最终门禁（Node 24.21.0；本机未发现 pwsh 7，使用 cmd 启动原生 Node CLI）：

| 门禁 | 实测结果 |
| --- | --- |
| lint / `tsc -b` | 通过，无错误/警告 |
| 完整 coverage | 169 文件、3802 用例，零失败、零跳过；语句 90.16%、分支 82.19%、函数 91.72%、行 91.57% |
| 相关测试额外严格类型检查 | 24 个 P8/本轮变更测试文件通过；不含原有 bootstrap/review-orchestrator 测试类型债务 |
| Markdown | 129 文件，零问题；另检查 104 个本地文件链接 |
| build / eval validate | 全部包构建通过，离线 fixtures 返回 ok |
| Playwright Chromium | 23/23，含桌面/窄屏及增强 E01/E02 完整流程 |
| docs:check / docs:build | 字段 677 条、enum 11 行、双语 26 对验证通过；54 页构建成功 |

coverage 使用 PostgreSQL 18.6、Redis 8.10.1（普通/OOM 独立实例）、SlikSVN 1.14.5
及 p4d 2025.1。最终命令增加 `--maxWorkers=2`：默认并行度曾在其他 C++ 构建占用
CPU/内存期间出现 8 个超时；未修改超时、用例或覆盖率阈值。每轮只关闭本轮创建的
临时服务，未操作其他构建进程。

主日志：`build/tmp/p8-validation/build/logs/p8-review-final-gates-serial.log` 及同目录
`p8-review-final-{coverage,browser,docs-check,docs-build}.log`。本轮新增 15 个单元/集成
用例，并加强已有 API、崩溃及浏览器断言；未将全仓覆盖率表述为 100%。

Linux 使用官方 SHA-256 校验的 Node 22.23.2、锁定 pnpm 10.20.0，在原生 tmpfs
中的独立 build 副本运行 `pnpm run ci`，仅给测试命令追加两个 worker 和 JSON
报告参数。169 个测试文件全部发现，3659 用例通过、50 跳过、零失败，59.82 秒；
lint、typecheck、Markdown、build、eval 依次通过。跳过项需要原生 PG/Redis/SVN/P4
服务或可执行文件；后端参数化用例在环境存在时才展开，因此不能将 Linux 用例数
与 Windows 直接相减当作遗漏。JSON 文件列表与 169 个源码测试文件逐一核对无缺失。
Linux Node 22 满足运行时要求，但低于文档站 Node >=23.6；文档站和浏览器证据来自
上方 Windows 验证。

首次在 Windows 盘 v9fs 上执行时，报告 3632 通过、3 失败、48 跳过，耗时
1367.58 秒，未到后续门禁。E05/Git metadata 超时，子进程启动也超时；单 worker
复跑时子进程报告 WAL 的 database locked。相同代码迁入原生 tmpfs 后，三个测试
文件 17 通过、2 个服务条件跳过、零失败；之后才同步最终连接清理修复并跑完整门禁。
没有据此为产品添加锁重试或放宽测试超时。原生验证通过
`build/tmp/p8-linux-native-artifacts` 链接保留；CI/JSON 报告复制到

# M40 社交 IM 复审与依赖、模型快照维护

复审 2026-10-12 以来的实现，修复 Slack、Discord、Telegram 回调、持久通知、消息渲染和 managed issue 生命周期中的边界问题。
同 delivery key 不同内容现在返回脱敏 409；Telegram 使用 safe-integer ID，Slack Socket 的完整握手有界且不支持响应载荷时仍空 ACK。

新旧 outbox 路径统一在最终配置、授权和 readiness 后通过 owner/fence 进入 sending，失租后不再 POST。
重试耗尽会产生终态通知，GitLab `web_url` 可跨 journal 恢复。
共享 Markdown 扫描保留括号链接和代码边界；managed issue 正文按 65,536 个 UTF-16 单元降级 resolved 详情，必要 fingerprint 超限则停止发布或关闭。
重复无效 verdict 不再误批准解决问题，triage 首轮和确认轮共用累计预算。
已有 token 的 Git fetch 不再调用系统 credential helper，避免 Git for Windows 的交互式 selector 在 agent 启动前阻塞。

workspace 依赖升级到当前兼容组合，Zod 4 配置解析、文档 introspection 和 TypeScript 6 项目构建同步迁移。
TypeScript 固定在 6.0.3，因为当前 typescript-eslint 的 peer 范围不支持 6.1/7.x；Node.js 下限为 22.23.4。
离线 models.dev 快照更新为 230 个 provider、8888 个模型，Kimi Coding 的目录提供方改为上游拆分后的 `kimi-code-plan-cn`。

本地验证覆盖真实 SDK loopback、SQLite 迁移、回调与发布恢复、重复刷新和多次部分修复；PostgreSQL/Redis 等专用服务端点按实际环境单独记录。
真实 Slack/Discord/Telegram 账户、公开回调、客户端显示和真实模型质量未在本次验收范围内，L01–L03 继续保留。

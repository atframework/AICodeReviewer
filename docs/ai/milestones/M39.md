# M39 Slack、Discord、Telegram 本地接入

新增 `slack_app`、`discord_bot`、`telegram_bot` Bot API 输出与 HTTP 四命令。
命名连接贯通配置编译、用途授权、秘密封装和管理表单；命令按精确用户、会话和仓库别名授权。
报告使用既有路由和模板，每渠道发送一条受限聚合消息，来源会话仅接收请求编号与状态。
协议验证使用 Slack 原始请求 HMAC、Discord Ed25519 和 Telegram webhook secret。

共享请求执行补齐持久 readiness、当前授权复查、固定配置快照、稳定队列交接、
忙 workspace 隔离、执行窗口与实际阶段计数。SQLite/PG 追加迁移 013，
Telegram 接收回复与请求原子入库；发送先取得 owner/fence，再进入持久 sending 状态。
不确定远端结果保持 unknown，过期 sending 不重发；只有明确限流回复允许到期重试。

2026-10-12 本地门禁通过：完整覆盖率发现 239 文件、5139 用例，
225 文件与 5107 用例通过，14 文件与 32 用例按环境条件跳过；覆盖率阈值通过。
真实本地 PostgreSQL、Redis 和独立 Redis OOM 实例参与完整测试，结束后服务及数据已清理。
lint、typecheck、构建、6 个离线 eval fixture、44 个浏览器用例、双语文档检查与 60 页站点构建通过。

三份 YAML 示例、默认离线注册工具和六篇双语指南已交付。
